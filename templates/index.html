What is ShieldScan

Built for the modern
threat landscape.

ShieldScan is a dual-layer phishing detection engine that combines machine learning with real-time URL, DOM, and domain analysis — giving you a plain-language verdict in seconds.

Real-time Analysis
Scans are processed on-demand in seconds. No queues, no waiting — just immediate threat intelligence when you need it.
Dual-Layer Detection
Layer 1 is a trained ML classifier. Layer 2 is a content-threat engine that reads actual page text and DOM to catch what the model alone might miss.
Full PDF Report
Export a detailed, structured PDF for every completed scan — including signal evidence, WHOIS data, model statistics, and a page screenshot.
Plain-Language Verdicts
No jargon. Every result is translated into a clear headline, risk level, and evidence list that anyone can understand without a security background.

How It Works

Six stages of
threat analysis.

Every scan runs through a structured pipeline. Each stage adds evidence — from URL structure to live page content — before a final verdict is produced.

1
URL Validation & Normalisation
The submitted link is cleaned, validated, and normalised. Private IPs, localhost addresses, and malformed inputs are rejected immediately.
Scheme check IP gate Redirect pre-check
2
Lexical Feature Extraction
30+ structural features are extracted from the URL string itself — length, special characters, subdomain depth, suspicious tokens, TLD risk, and more.
URL length Hyphen count Token analysis TLD risk
3
Domain & WHOIS Intelligence
The domain is resolved via DNS, registration metadata is fetched from WHOIS, and signals like domain age, registrar, and country are recorded.
DNS resolution Domain age Registrar check
4
Browser Simulation & DOM Extraction
A headless browser loads the page and extracts DOM features — form counts, password fields, external resource ratios, iframes, and a screenshot.
Headless Chrome DOM features Screenshot
5
Machine Learning Inference
All collected features are assembled into a vector and fed to the trained ML classifier. It outputs a phishing probability score, confidence, and top signal weights.
Random Forest Risk score Feature importance
6
Content Threat Classification
The extracted page text is scanned for threat categories — credential phishing, financial scam, fake shops, gambling, and more — using a keyword-weighted scoring engine.
Layer 2 detection Keyword scoring Threat categories
